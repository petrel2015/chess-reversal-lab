# FAQ

关于项目范围与行为的常见问题速答。更深入的背景见[功能索引](./features/index.md)。

**它真的能把理论败局逆转吗？**
不能——应用自己也这么声明。"逆转"指的是探索*你*能否找到出路；Stockfish 始终为你指定的那一方走出最强着法。如果该方在理论上已败，评估会如实展示你在输。

**为什么自定义局面里不能王车易位、也不能吃过路兵？**
凭空构造的局面没有历史信息，这些权利无法一致地推导。因此自定义摆法默认不带易位权、也没有吃过路兵机会；"标准开局"预设则保留完整易位权。详见[自定义残局摆设设计](./features/custom-position-setup.md)。

**可以选兵升变成什么吗？**
目前不能，固定升后。

**能导入或导出 FEN/PGN 吗？**
v0.1.0 不支持。局面只能通过棋子库手工摆放，没有文件导入、剪贴板整合或 URL 分享。

**悔棋只撤我自己的半步吗？**
不是。悔棋撤回完整的一个回合：你最近一步加引擎的应手。恢复会重放这一对；若恢复后轮到引擎，它会重新计算应答而不是沿用旧手。见[悔棋与回看设计](./features/move-history-controls.md)。

**回看模式能修改历史然后分叉吗？**
回看是只读的——回退能看到历史盘面，但期间尝试落子会被拒绝。想分叉请悔棋，或在摆棋模式里用"从当前局面重摆"。

**AI 执哪一方？**
只有一方：你指定为获胜方的那一色。另一方完全由你模拟。

**这里的引擎有多强？**
是 Stockfish 17.1 的单线程 WASM 构建，32 MB 置换表，每步思考时间上限 3 秒——作为浏览器工具很强，但不能与时限更长、多核并行的分析配置相比。

**刷新页面棋局还在吗？**
不在。任何对局内容都不持久化；只有界面语言会在刷新后保留。见[隐私说明](./privacy.md)。

**离线能用吗 / 能装成应用吗？**
可以添加到 iPhone 主屏幕，也有相应的 Web 应用元数据，但没有 Service Worker，离线可用性不做承诺。

**能把当前局面生成链接发给朋友吗？**
目前不能。URL 从不编码棋盘状态。

**它能替我在 chess.com/lichess 上落子吗？**
不能，而且这是明确的非目标：本工具绝不与第三方国际象棋平台交互。
