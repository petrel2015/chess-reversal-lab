# 使用指南

本指南说明日常如何操作逆转棋局，包括那些通过状态提示表达的边界行为。各功能"是什么、为什么"见[功能索引](./features/index.md)。

## 打开工具

访问 <https://petrel2015.github.io/chess-reversal-lab/>。首次载入需要编译 Stockfish WASM 引擎（数秒），顶部状态胶囊显示"引擎载入中"，Stockfish 报告就绪后消失。资源加载完成后不再产生网络请求。

![总览](../img/overview-zh.webp)

## 切换语言

右上角开关在中（中文）/ EN（English）之间切换。首次访问会按浏览器语言自动选择；手动选择保存在 `localStorage` 的 `locale` 键下，之后始终优先。

细节见[国际化设计](./features/internationalization.md)。

## 摆一个自定义残局

进入页面即处于**摆棋模式**，默认已加载标准开局。

### 选择起始预设

- **标准开局** —— 32 枚棋子，保留完整王车易位权。
- **空棋盘** —— 全部清空，每枚棋子都由你亲手摆放。

两个预设都只是起点，之后仍可继续增删调整。

### 放置与移动棋子

- 在两侧颜色的棋子库中点选一枚棋子，再点击棋盘格放置。棋子库有数量上限（单色：王 1、后 1、车 2、象 2、马 2、兵 8）；用完后按钮禁用并在状态栏说明。
- 可以从库拖拽到棋盘，把棋盘上的棋子拖回己方棋子库即可移除，也可以在格与格之间拖动。
- 点击棋盘上已有的棋子会选中它；再点击另一格则移动，目标格有棋子时两者交换位置。
- 兵不能放在第一排或第八排，应用会直接拒绝并提示，而不是悄悄换位。
- 选中棋盘上的棋子时，右侧面板提供"放回棋子库"和取消操作。

### 合法性校验

只有满足以下全部条件，开始按钮上方的校验卡才会变绿：

1. 双方各有且只有一个王。
2. 两王不相邻。
3. 第一/第八排没有兵。
4. 不是双方同时被将军。
5. 未轮到走的一方不处于被将军状态。

任一条件未满足时开始按钮保持禁用，旁边给出具体原因。

## 配置对局

- **希望哪方获胜？** 白方或黑方。该方整局由 Stockfish 控制，且永远走出它认为最佳的着法。
- **接下来谁走？** 白方或黑方先行。
- **AI 思考时间** —— 每步 0.4–3.0 秒（默认 1.2 秒）。时间越长搜索越深，节奏越慢。

## 开始推演

校验通过后点击**开始推演**。应用会记住开局快照，方便之后回到摆棋模式。若开局就轮到引擎，它会立即开始思考（约 180 毫秒调度延迟 + 你设定的思考时长）。

## 行棋对弈

- 你的回合：点击己方棋子，合法落点会高亮，再点击目标格完成走子。非法目标只会收到拒绝提示，不会移动任何东西。
- 引擎回合到时自动落子。
- 兵的升变固定升为后，没有选择弹窗。
- 出现将死、逼和、三次重复、子力不足、五十回合规则时对局结束，终局描述显示在状态栏并同步到胜算条。

面板在每个半步后都会更新：

![对局视图](../img/match-analysis-zh.webp)

## 读懂局面面板

- 双方**子力明细**与配色。
- **子力差**采用通用价值（兵 1、象/马 3、车 5、后 9），双方分别显示，如 `+3 / −3`。
- **胜算估计条** —— 只是估计，界面明确标注"不代表理论必胜"。来源会切换并注明：
  - 对局中：Stockfish 评估（杀棋分映射为约 99%/1%，其余用 centipawn 的 logistic 曲线）
  - 首次评估前：按原始子力差估算
  - 回看模式：冻结在所查看的半步
  - 终局：精确结果（将死 → 100%/0%，和棋 → 50%/50%）

评估文案始终以指定获胜方的视角表述（如"指定方明显优势 +2.3""可强制将死 · M5"）。

## 改变棋局走向

- **悔棋**撤回一个完整回合：你最近的一步加上引擎的应手（如有）。可以连续悔多回合。
- **恢复**按原样重放被撤销的回合。特例：如果恢复后轮到引擎走，引擎会重新计算应答——旧应答被有意丢弃。
- **回看 ← / →**逐步浏览当前对局的任意半步而不影响对局本身。回看时点击棋盘会被拦截并提示；用"下一步"回到最新局面即可恢复操作。回看从不改动实际对局、行棋记录或恢复栈。
- **重摆开局**回到本局开始前的确切摆法。
- **从当前局面重摆**把*现在*的局面设为新的可编辑起点，并保持正确的行棋方。

引擎思考期间你的点击会被忽略，直到它的着法落下；悔棋会通过引擎 `stop` 指令安全取消当次搜索。

## 翻转棋盘视角

翻转按钮把视角旋转 180°。只影响显示层——不会重置棋局、也不改变任何规则；两侧棋子库随之互换，保证贴近手边的一方对应下方棋子库。

## 捐赠

页脚有支付宝 / 微信按钮。桌面端弹出二维码模态框；移动端支付宝先尝试通过 URL scheme 唤起 App，失败则回落到二维码弹窗。ESC 或点击遮罩关闭。

## 错误处理一览

| 情况 | 行为 |
| --- | --- |
| 引擎文件加载失败 | 状态胶囊显示"引擎不可用"，提示刷新页面；可以摆棋但 AI 无法落子 |
| 引擎返回无法执行的着法 | 状态栏标记错误信息，当前局面保持不变 |
| 选择了已用完的棋子 | 棋子库按钮禁用，消息提示已达上限 |
| 走出非法着法 | 不移动，并给出合法性提示（例如"兵不能后退"） |
| 回看时点击棋盘 | 拒绝并提示"正在回看第 x/y 步" |

遇到诸如页面一直停留在"引擎载入中"的问题，参见[常见问题排查](./troubleshooting.md)。
