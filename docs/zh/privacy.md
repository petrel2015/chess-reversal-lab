# 隐私说明

以下描述基于 v0.1.0 的源码逐项核对。一句话概括：对局数据从不离开你的浏览器，而且应用几乎什么都不存。

## 应用存储了什么

| 内容 | 位置 | 存续时间 |
| --- | --- | --- |
| 界面语言（`locale`） | `localStorage` | 直到清除站点数据 |

这是唯一的持久化记录。局面、行棋、配置选择（获胜方、思考时长）、回看状态都只存在于内存中；刷新页面即全部丢弃。

## 网络行为

- 应用在运行时**不发起**任何 API 调用：没有后端、没有统计埋点、没有第三方字体或 CDN。
- 静态资源（HTML/JS/CSS、棋子图片、Stockfish `stockfish.js` + `.wasm`、捐赠二维码）加载时同源取自 GitHub Pages。
- 规则判定由页面内的 chess.js 完成；引擎搜索在 Web Worker 内跑 WASM——两者都是完全本地的计算。

## 第三方交互

- **捐赠按钮**是唯一有意的对外出口：移动端点击支付宝会尝试经 `alipays://` scheme 唤起支付宝；桌面端与微信展示仓库内的静态二维码图片。是否完成支付完全发生在你与相应平台之间。
- 运行时其余部分没有任何外链跳转。

## 权限

应用不请求任何浏览器权限（通知、定位、摄像头、剪贴板写入等均无）。

## 注意事项

- 本应用自身不做跟踪，但 GitHub 的托管设施可能按其条款记录标准请求元数据，这超出本项目控制范围。
- 由于没有账号体系，任何内容都不会跨设备同步或恢复。

实现参考见[架构说明](./architecture.md)及 `app/lib/i18n.tsx` / `app/lib/use-engine.ts` 源码。
