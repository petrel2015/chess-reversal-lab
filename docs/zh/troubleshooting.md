# 常见问题排查

这里收录真实的故障模式、成因与修复方法。状态提示主要出现在顶栏胶囊与棋盘上方的横幅里。

## 页面一直显示"引擎载入中"

**现象：** 状态胶囊始终不变成"已就绪"；开始推演后 AI 沉默。

**原因与修复：**

1. `/engine/stockfish.js` 或 `stockfish.wasm` 不可访问——查看开发者工具的网络面板。在 GitHub Pages 上通常意味着构建或 basePath 不匹配；确认 URL 形如 `/chess-reversal-lab/engine/stockfish.wasm`。
2. 设备阻止了 WASM 编译（少见，某些加固型浏览器会这样）。换一个浏览器试试。
3. 缓存了旧版 HTML 却引用新资源名。强制刷新（Cmd/Ctrl+Shift+R）。

修复后请重新加载页面——Worker 每次页面加载只创建一次，当前没有页内重试按钮。

## "引擎不可用"

Worker 在启动期间触发了错误事件（加载失败或中止）。刷新页面；若持续出现，回到上一条检查资源可达性。

## AI 不落子

- 确认确实轮到 AI：横幅显示"AI 回合"，且侧栏摘要标明了 Stockfish 控制的颜色。
- 如果在它思考时按了悔棋，这是预期行为：悔棋会取消搜索并把行棋权交还给你。
- 正在回看？回看游标激活时走子被拦截——用"下一步"回到最新局面。

## 开始按钮不可点

直接阅读它上方的校验卡。常见原因：缺少某一方的王、两王相邻、第一/第八排有兵、未行棋方已被将军。调整摆法直到卡片变绿。

## 棋子放不下去

- 该类型/颜色的棋子可能已经用完——库中按钮显示 ×0 并禁用。
- 兵按设计不能放在第一和第八排。
- 你可能正要放到对方棋子库里；棋子只能放回自己颜色的库。

## 语言没记住 / 出现混排

手动选择保存在 `localStorage` 的 `locale` 键下。清除站点数据会恢复自动探测。若切换后状态栏文案滞后，刷新一次——v0.1.0 已在语言变化时自动重推导标准消息，但浏览器缓存的旧 HTML 可能在脚本执行前短暂显示另一种语言。

## 构建失败

- `npm test` 在构建阶段失败 → 先修构建；测试刻意要求先有全新的生产构建产物（`dist/`）才运行断言。
- 静态导出报 TypeScript 错误 → 该构建使用 `tsconfig.pages.json`；确保新代码在两份配置下都能编译。
- CI 里 Pages 部署失败 → 打开工作流日志；最常见原因是提交的锁文件与代码不同步（本地跑 `npm ci` 验证），修好后重新推送。

## 仍未解决？

请到 [Issues](https://github.com/petrel2015/chess-reversal-lab/issues) 反馈，附上浏览器与系统版本、受影响的是线上还是本地构建，以及界面显示的确切状态文案。
